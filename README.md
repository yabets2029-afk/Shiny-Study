# Deadline Creator

Deadline Creator is a simple productivity app designed to help students manage their academic deadlines efficiently. The app allows users to create deadlines for assignments, projects, and exams while receiving timely reminders.

## Features

* **Create Deadlines**
  Easily add deadlines for assignments, exams, or personal study goals.

* **Expanded Notifications**
  Receive detailed reminders that include task information, urgency level, and remaining time before the deadline.

* **Student-Focused Interface**
  A clean and minimal design to help students stay organized and focused.

## Development

The application's **UI design and backend implementation were developed with the assistance of AI tools**, which helped speed up development and improve the overall structure of the system.

## Purpose

This project was created to provide students with a simple tool to track deadlines and avoid missing important academic tasks.
